# Сборка

Интерактивное 3D-портфолио фронтенд-разработчика Сейт-Ахмета Балаева. Включаешь компьютер, прокручиваешь страницу и рассматриваешь компоненты. За видеокартой — шоурум Velocity Atelier, за памятью — музыкальные инструменты Resonance, за водоблоком — CoolerScreen, за резервуаром — Vivid, за материнской платой — Horizon.

На мониторе можно открыть папку «Проекты», браузер Horizon и блокнот «обо мне.txt». Клавиатура и мышь в сцене реагируют на взаимодействие. Команда выключения гасит монитор, снижает яркость подсветки и скорость вентиляторов, затем возвращает камеру к кнопке питания. Быстрые ссылки на проекты и контакты доступны с первого экрана.

## Локальный запуск

Проверено с Node.js 24. Для просмотра достаточно браузера с поддержкой WebGL 2 и готовой модели из репозитория.

```sh
npm ci
npm run dev
```

Открой [http://127.0.0.1:5260/](http://127.0.0.1:5260/).

```sh
npm run build
npm run preview
```

Сборка записывается в `dist/`. Локальный предпросмотр сборки доступен на [порту 5261](http://127.0.0.1:5261/).

## Архитектура

Сайт состоит из статической HTML-страницы, сцены Three.js и интерфейса на JavaScript и CSS. Vite собирает приложение и выносит Three.js в отдельный чанк. В проекте нет серверных маршрутов, базы данных и обязательных переменных окружения.

| Модуль | Ответственность |
| --- | --- |
| [`index.html`](index.html), [`portfolio.js`](src/portfolio.js) | Текстовые разделы, быстрый каталог проектов и контакты. Каталог и контакты открываются до включения 3D-компьютера. |
| [`main.js`](src/main.js) | Загрузка модели и экранов, цикл кадров, состояния питания, ввод и синхронизация прокрутки с камерой и подписями. |
| [`path.js`](src/path.js) | Ключевые ракурсы, положение и цель камеры, угол обзора и сдвиг кадра. Позиция и направление интерполируются сплайном Catmull–Rom. |
| [`scene.js`](src/scene.js) | Загрузка GLB через Draco, привязка узлов и материалов, освещение и анимация вентиляторов, охлаждающей жидкости и подсветки. |
| [`screens.js`](src/screens.js) | Шейдер монитора, текстуры дисплея водоблока и POST-индикатора, обои, часы и загрузочный экран. |
| [`desktop.js`](src/desktop.js), [`keys.js`](src/keys.js) | Рабочий стол, окна и меню, браузер внутри монитора, обработка нажатий по 3D-клавиатуре и мыши. |
| [`projects.js`](src/projects.js) | Общий каталог работ для папки на мониторе и быстрого списка сайта. |

### Как работает монитор

Издалека рабочий стол рисуется текстурой в шейдере. При приближении камеры его заменяет интерактивный DOM. Код проецирует четыре угла поверхности монитора на экран браузера и рассчитывает гомографию для CSS `matrix3d()`. Встроенные в текстуру значки отключаются на время показа DOM, поэтому возле точки переключения два слоя значков не накладываются. Проекты, допускающие встраивание, открываются в iframe, а для остальных используется внешняя вкладка.

### Производительность

- Сцена поставляется как GLB со сжатием геометрии Draco. Модель и декодер обслуживаются как статические файлы.
- До показа сцены загружаются текстуры и прогревается рендер. Обои монитора анимируются в шейдере, а текстура часов обновляется при смене минуты.
- Затенение GTAO рассчитывается в половинном разрешении. Если сцена долго рисуется медленно, приложение сначала уменьшает разрешение рендера, затем отключает GTAO.

## 3D-геометрия и экспорт

Геометрия компьютера и стола генерируется в Blender скриптами Python из [`tools/blender/`](tools/blender/). Размеры деталей заданы в миллиметрах в [`layout.py`](tools/blender/layout.py), материалы собраны в [`mats.py`](tools/blender/mats.py), генераторы отдельных компонентов находятся в [`parts/`](tools/blender/parts/). Имена узлов и материалов связывают экспорт с анимациями и экранами в Three.js.

Для повторного экспорта запусти из корня репозитория с установленным Blender 5.2:

```sh
blender -b --factory-startup --python tools/blender/build.py -- --export
```

Скрипт перезаписывает [`public/models/sborka.glb`](public/models/sborka.glb). Опции `--save` и `--shot` используют локальный путь `D:\sborka-work`, заданный в [`build.py`](tools/blender/build.py). Для сборки сайта Blender не нужен.

## Развёртывание

На Vercel используется пресет Vite. Команда сборки — `npm run build`, выходной каталог — `dist`. Готовый сайт раздаётся как статические файлы. Предварительно экспортированная модель, декодеры и превью входят в сборку.
